# Autoclave Steam Monitor — QCONBP

แดชบอร์ดติดตามความดัน อุณหภูมิ ไอน้ำ และการดูดสุญญากาศของ Autoclave 1–8
ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ CSV ไม่ถูกส่งออกไปที่เซิร์ฟเวอร์ใด

## โครงสร้างไฟล์

```
index.html            ← ตัวแดชบอร์ด (ไฟล์เดียวจบ)
data/
  Q2_20260801.CSV     ← ไฟล์จาก data logger วางไว้ตรงนี้
  Q2_20260731.CSV
  index.json          ← ไม่บังคับ ช่วยให้โหลดเร็วขึ้น
README.md
```

## วิธีขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub ตั้งชื่อเช่น `autoclave-dashboard`
2. อัปโหลด `index.html` และโฟลเดอร์ `data/` เข้าไป
   (ปุ่ม **Add file → Upload files** ลากไฟล์เข้าไปได้เลย ไม่ต้องใช้ git)
3. ไปที่ **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` / โฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้ลิงก์
   `https://<ชื่อผู้ใช้>.github.io/autoclave-dashboard/`
5. ส่งลิงก์ให้ทีมงานได้เลย เปิดได้ทั้งคอมและมือถือ

## การอัปเดตข้อมูลรายวัน

อัปโหลดไฟล์ CSV ของวันใหม่เข้าโฟลเดอร์ `data/` เท่านั้น ไม่ต้องแก้ `index.html`

หน้าเว็บจะไล่หาไฟล์ย้อนหลังจากวันนี้ไปไม่เกิน 45 วัน แล้วเปิดไฟล์ล่าสุดที่เจอให้อัตโนมัติ
ผู้ใช้เลือกได้ว่าจะดึงกี่วัน (1 / 3 / 7 / 14 วัน) จาก dropdown มุมขวาบน
และยังกดเปิดไฟล์จากเครื่องตัวเองได้เหมือนเดิม

### ไฟล์ index.json (ไม่บังคับ)

ถ้าอัปโหลดไฟล์ไม่ต่อเนื่องทุกวัน การไล่เดาชื่อไฟล์จะช้าลงเล็กน้อย
แก้ได้ด้วยการวางไฟล์ `data/index.json` ที่มีรายชื่อไฟล์ทั้งหมด แล้วหน้าเว็บจะอ่านจากไฟล์นี้แทน

```json
[
  "Q2_20260730.CSV",
  "Q2_20260731.CSV",
  "Q2_20260801.CSV"
]
```

เพิ่มชื่อไฟล์ใหม่ต่อท้ายทุกครั้งที่อัปโหลด CSV

## การตั้งค่าในไฟล์

เปิด `index.html` แล้วแก้ค่าที่บล็อก `ตั้งค่าการดึงไฟล์อัตโนมัติ` ใกล้ต้นสคริปต์

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `DATA_DIR` | `data/` | โฟลเดอร์ที่เก็บ CSV |
| `DATA_PREFIX` | `Q2_` | คำนำหน้าชื่อไฟล์ |
| `DATA_EXT` | `.CSV` | นามสกุลไฟล์ |
| `LOOKBACK` | `45` | ไล่หาย้อนหลังกี่วัน |

รูปแบบชื่อไฟล์ที่รองรับคือ `<PREFIX><YYYY><MM><DD><EXT>` เช่น `Q2_20260801.CSV`

## ข้อควรระวังเรื่องข้อมูล

GitHub Pages ใช้ได้ฟรีเฉพาะกับ repository แบบ **public** ซึ่งแปลว่าไฟล์ CSV
ในโฟลเดอร์ `data/` ใครก็เปิดอ่านได้ถ้ารู้ลิงก์ ถ้าข้อมูลการผลิตเปิดเผยไม่ได้ ให้เลือกทางใดทางหนึ่ง

- ใช้ repository แบบ private (ต้องมี GitHub Pro หรือ Team ถึงจะเปิด Pages ได้)
- อัปแค่ `index.html` ขึ้น GitHub ส่วน CSV เก็บใน intranet แล้วชี้ `DATA_DIR` ไปที่นั่น
- ย้ายไปโฮสต์ที่ล็อกอินได้ เช่น Cloudflare Pages + Cloudflare Access
